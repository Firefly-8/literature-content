## 山行

**作者**：杜牧（唐代）

**原文**：
远上寒山石径斜，白云生处有人家。
停车坐爱枫林晚，霜叶红于二月花。

**创作背景**：
《山行》是晚唐诗人杜牧的代表作之一，具体创作时间难以确考，一般认为是他任官期间游历山中所作。诗中描绘了诗人于深秋时节远行山路时的所见所感，诗中"寒山""霜叶"等意象明确点明了时令。据考证，诗中所写的地点可能在今湖南长沙岳麓山一带，但亦有学者认为泛指杜牧游历的某处秋山。全诗通过对深秋山林景色的细腻描绘，表达了诗人对自然美景的由衷赞叹与热爱。

**字词注释**：

| 词语 | 释义 |
|------|------|
| 山行 | 在山中行走、游览 |
| 远上 | 远远地向上延伸 |
| 寒山 | 深秋时节带有寒意的山 |
| 石径斜 | 石头小路蜿蜒曲折；"斜"读xié，押韵 |
| 白云生处 | 白云缭绕升腾的地方；"生"有飘动升起之意 |
| 人家 | 住着住户 |
| 停车 | 停下马车 |
| 坐 | 因为 |
| 枫林晚 | 傍晚时分的枫树林 |
| 霜叶 | 经霜打过的枫叶 |
| 红于 | 比……更红 |

**翻译**：
沿着弯弯曲曲的石头小路，远远地登上深秋的寒山，在那白云升腾飘绕的地方，隐隐约约可以看见几户人家。我停下马车来，是因为太喜爱这傍晚时分的枫林景色——那经霜的枫叶，比春天二月的鲜花还要红艳动人。

**赏析**：

《山行》是一首脍炙人口的写景抒情小诗，全诗仅四句二十八字，却以精妙的构思和生动的笔触，勾勒出一幅色彩明艳的深秋山行图，堪称咏秋诗中的千古绝唱。

**一、意象丰富，层次分明。** 全诗选取了"寒山""石径""白云""人家""枫林""霜叶"等一系列典型意象，前两句以"远上"二字领起，将读者的视线从脚下的石径引向远处的寒山、白云和人家，由近及远、由低至高，画面极具纵深感与层次感。"寒山"点明深秋时节的清冷氛围，而"白云生处有人家"则为这幅秋景图增添了人间烟火的温暖与诗意，使画面既清幽又不失亲切。

**二、巧用对比，意蕴深刻。** 全诗最精彩之处在于第三、四句的精妙对比。诗人以"霜叶"与"二月花"进行对照，自古以来，春花象征着美好与繁盛，而秋风扫落叶则往往引发悲秋之情。然而杜牧却反其意而用之，说经霜的枫叶比春花还要红艳。这一对比不仅写出了霜叶色彩的绚烂夺目，更寄托了诗人积极向上、豁达乐观的人生态度——秋天的壮美并不逊于春天，霜打之后的枫叶反而焕发出更加蓬勃的生命力，蕴含着深刻的人生哲理。

**三、炼字精到，以景结情。** 诗中用字极为考究。"斜"字生动地写出山路的蜿蜒曲折，"生"字赋予白云以动态的飘动感，使画面充满生机。"晚"字一语双关，既指时间上的傍晚时分，又暗含诗人对这暮色中枫林美景的无限眷恋。"红于"二字以一个"于"字构成比较，语气肯定而有力，将诗人对霜叶的赞美之情推向高潮。全诗不着一"情"字，却以景结情，诗人对大自然的热爱与陶醉已溢于言表。

**四、结构精巧，卒章显志。** 全诗前三句层层铺垫：一路远行，所见皆秋景之美，而诗人仍觉意兴未尽，直到看见那片霜染枫林才终于驻足流连。末句"霜叶红于二月花"如豹尾一收，既是对前三句的总括升华，又是全诗的点睛之笔，将一首普通的山行记游之作提升到哲思的高度，令人回味无穷。

*总结：杜牧以其敏锐的观察力和高超的艺术表现力，将一幅深秋山林图描绘得色彩斑斓、意境深远。这首诗打破了"悲秋"的传统主题，以积极昂扬的笔调歌颂了秋天独特的美，千百年来深受读者喜爱，成为传诵不衰的经典名篇。*
