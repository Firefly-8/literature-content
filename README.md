## 内容格式

### 书籍深度阅读指南（90 本）
每本包含：内容摘要（作者背景、核心论点、章节脉络、关键概念）+ 如何阅读（四大问题分析法）

### 古诗赏析（255 首）
每首包含：原文、创作背景、字词注释、白话译文、艺术特色赏析

### 四大名著人物志（200 人物）
每个人物包含：身份、关键事件、性格特点、人物关系、经典语录、人物赏析

### 名著导读（70 本）
每本包含：基本信息、故事梗概、核心主题、艺术特色、推荐理由

### 文学常识题库（500 题）
按朝代/作者/作品/流派分类，包含选择/填空/判断题型

## 数据源

由 LongCat-2.0 模型生成，涵盖心理学、经济学、哲学经典著作深度解析。
